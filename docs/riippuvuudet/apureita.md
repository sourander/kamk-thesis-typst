# Apureita

Typstin kirjoittamiseen on olemassa useita apureita. Osa on online-palveluita, osan voi ladata koneelle. Tämä dokumentti on tarkoitettu niiden listaamiseksi. Kun opiskelijat löytävät uusia apureita, lisään niitä tähän dokumenttiin.

1. [TypstPad](https://typstpad.com/) on matemaattisen kaavan muotoiluun interaktiivinen työkalu.
2. [Advanced Table Editor](https://www.latex-tables.com/?format=typst&force) on taulukon kasaamiseen interaktiivinen työkalu.
3. [Table Editor](https://truben.no/table/typst) on kilpailija yllä mainitulle. Se tekee taulukoita.
