# Zotero

Zotero on ilmainen ja avoimen lähdekoodin viitteidenhallintaohjelma, joka on saatavilla Windowsille, Macille ja Linuxille.

Asenna se Zoteron omien ohjeiden mukaan: [Installation Instructions](https://www.zotero.org/support/installation).

## Zotero Connect

Zotero Connect on selainlaajennus, joka mahdollistaa viitteiden lisäämisen suoraan selaimesta. Se on saatavilla Firefoxille, Chromelle ja Safarille. Asenna se Zoteron omien ohjeiden mukaan: [Zotero Connect](https://www.zotero.org/support/connector).

## Käyttöohje

Zoteron käyttö on helpompi esitellä videolla kuin tekstinä, joten käyn aihealueen läpi vain ja ainoastaan tämän materiaalin videoversiossa.
